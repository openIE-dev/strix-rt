<s># Batched prefill (`crates/prefill`)  Batched prompt processing for strix-rt on the Radeon 8060S (gfx1151, RADV). It replaces the token-by-token decode loop for the prompt. Status: **qwen38 (qwen35 arch) works and matches the decode path. lfm2 is not done yet.**  ## Layout - `shaders/pf_gemm.comp`: quantized-weight x f16-activation GEMM using KHR_cooperative_matrix (f16 x f16 -> f32,   16x16x16, wave32). The weight format is a spec constant and covers every rtcore::qtype: Q4_K, Q6_K, Q5_K, Q8_0,   IQ4_NL, IQ4_XS, Q3_K and IQ3_S, decoded by `pf_deq.glsl` (adapted from vkrt `q_any`).   - Workgroup tile is 128 (m) x 128 (n) x 32 (k), with 8 waves each owning a 32x64 tile (2x4 accumulators).   - Shared A/B tiles are double-buffered. Global A loads and the B dequant for step k+1 go into registers before the     MMAs of step k, so there is one barrier per k-step.   - m-tiles are scheduled fastest, so the 4 workgroups that share a weight row-tile at M=512 hit L2 together.   - Residual accumulation is fused (flags bit0). y_col writes into a column window of a wider output, so     [qkv|z|alpha|beta] and [gate|up] land side by side without copies.   - Edge tiles use a guarded store staged through shared memory. - `GemmOp` / `Pf::gemm` is the GEMM interface. One call covers the row range [row0, row0+rows) of a weight, which lets an   NPU (crates/npu) take part of N while the GPU does the rest into the same Y via y_col. - `pf_rmsnorm`: f32 residual to f16 normalized activations. - `pf_gdn_conv` / `pf_gdn_convst`: batched causal conv1d + SiLU + q/k L2 norm, reading tokens before the chunk from the   conv state. A separate pass then writes the final state. - `pf_gdn_scan`: Gated DeltaNet recurrence. One workgroup per value head, each thread holds one state row in   registers, and tokens are staged 16 at a time in shared memory. - `pf_gnorm`: gated RMSNorm. - `pf_rope`: per-head q/k norm + partial NeoX RoPE + f16 KV write at pos0+t. - `pf_attn`: causal GQA flash-style attention over the f16 cache, 16 tokens x 1 head per workgroup, with the sigmoid   output gate applied. - `pf_swiglu`. - `qwen35::prefill(pf, model, scratch, prompt)` is the function the model calls. It resets the recurrent state and runs   prompt[..L-1] batched (chunks of `PF_M`, default 512, at any pos0). It writes kc/vc, the conv state and the   DeltaNet state exactly where decode would. The last prompt token then goes through the model's own decode step, so   logits, argmax and toks[L] come from the decode code and generation continues with `ctx.submit_repeated(step, n)`.
