## Reference and test harnesses that link third-party code (built separately, not part of the Rust workspace)

- `crates/mcv/ref/mcvdump.cpp`, `logs/glimmer/mtmd/mtmd_dump.cpp`: link against llama.cpp / mtmd (MIT).
- `crates/ternary/tools/fork_dequant.c`: links ggml from a llama.cpp fork (MIT upstream).
- `logs/n35/jpgtest/stbdump.c`: includes `stb_image.h` (not vendored here).
- Python reference scripts under `crates/*/ref/` import PyTorch, transformers, diffusers, gguf-py and similar packages from your
  own environment. None of them are vendored.
- `tools/comp/vpatch/`: the patched vLLM / triton_kernels `opt_flags.py` used in one experiment is **not** redistributed. Only the
  one-line diff is described.

## Rust dependencies (crates.io, not vendored)

All permissively licensed, according to `cargo metadata` on this tree: MIT OR Apache-2.0 (ash, anyhow, half, image, png, serde, serde_json,
memmap2, libc, unicode-normalization, ...), plus MIT (crunchy, simd-adler32, zmij), ISC (libloading), Zlib (zlib-rs),

## System libraries used at build or run time (not vendored)

Vulkan loader + Mesa RADV, shaderc `glslc`, AMD XRT (`libxrt-dev`, `libxrt_coreutil`), the Linux kernel headers for `kmod/strixpc`.
